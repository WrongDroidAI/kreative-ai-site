KreativeAI

Tab Panic Button Install Guide

This is a Microsoft Edge / Chromium extension that organizes open tabs into clean, color-coded tab groups and creates a plain-text project summary.

Download Extension ZIP

Install In Microsoft Edge

  1. Download the ZIP file and unzip it.
  2. Open edge://extensions.
  3. Turn on Developer mode.
  4. Click Load unpacked.
  5. Select the unzipped kreativeai-tab-panic folder, the one containing manifest.json.
  6. Pin the extension icon, then click it to run Clean My Tabs.

Install In Chrome, Brave, Or Arc

  1. Download and unzip the extension.
  2. Open chrome://extensions.
  3. Turn on Developer mode.
  4. Click Load unpacked and select the unzipped folder.

Privacy

The extension uses browser permissions for tabs, tab groups, and local storage. It has no host permissions and makes no network calls.
