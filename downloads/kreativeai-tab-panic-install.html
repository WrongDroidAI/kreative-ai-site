KreativeAI

Tab Panic Button Install Guide

This is a Microsoft Edge / Chromium extension that organizes open tabs into clean, color-coded tab groups and creates a plain-text project summary.

Download Extension ZIP

Install In Microsoft Edge Or Any Chromium Browser

  1. Unzip the file. You will get a folder called kreativeai-tab-panic.
  2. Either use the easy path: double-click Install.cmd inside the folder. It opens Edge to the extensions page and copies the folder path to your clipboard. Then follow steps 3 through 5.
  3. Or install manually: open edge://extensions in Edge.
  4. Turn on Developer mode, using the toggle at the bottom left.
  5. Click Load unpacked and select the unzipped kreativeai-tab-panic folder, the one containing manifest.json.
  6. Open the puzzle-piece menu in your toolbar, find KreativeAI Tab Panic Button, and click the pin icon next to it.
  7. Click the K icon on your toolbar and hit Clean My Tabs.

Privacy

The extension uses browser permissions for tabs, tab groups, and local storage. It has no host permissions and makes no network calls.
